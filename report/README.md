# Model Evaluation Report (`/report`)

This directory will contain the required one-page model report and evaluation artifacts, including:
- Task description
- Dataset and data splits (PlantVillage train/val & field-condition test set)
- Model architecture details
- Performance metrics (Macro-F1 score, Accuracy)
- Confusion Matrix
- Per-class Precision and Recall
- Baseline model comparison
- Model limitations and future work
